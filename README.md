# The 2 Mile Pastor

Responsive static demo for The 2 Mile Pastor / Second Mile Ministries. Open `index.html` in a modern browser. Giving and checkout only simulate confirmation. Sample merchandise and prices are illustrative.

The website uses the supplied palette and typography as art direction. The highway and product photography are newly generated for this demo. Headings use [Bebas Neue](https://fonts.google.com/specimen/Bebas+Neue), body copy uses [DM Sans](https://fonts.google.com/specimen/DM+Sans), and controls use [Oswald](https://fonts.google.com/specimen/Oswald). Another Danger is omitted because a licensed webfont was unavailable.

For GitHub Pages, publish the root of the `main` branch.
